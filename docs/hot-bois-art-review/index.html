Hot Boi's Tavern — Interior Art (P0)

Branch agent/hot-bois-interior-art. Core surfaces, the three-part bar, Hot Boi's proprietor billboard, and the central pillar — the P0 set the task brief calls "must complete before proceeding." Every in-engine screenshot here is the real renderer (vite preview), reached by temporarily wiring each asset onto a real Floor 1 wall/cell, screenshotting, then reverting the floor data — only the art files and registry entries are committed.

Per the brief's own P0 priority order (item 9: "review these together before proceeding") — this is a stop point. P1 (hearth, chandelier, furniture, kitchen) has not been started.
