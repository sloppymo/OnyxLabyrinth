## Historical and session material

The following directories contain session prompts, handoffs, plans, and dated playtest notes. They are useful for context and archaeology, but they are not the source of truth for current work unless explicitly marked current in `docs/AGENT-READING-LIST.md`.

- `docs/PROMPT-*.md` — One-off session prompts.
- `docs/FOLLOWUP-*.md` — Session handoff/followup prompts.
- `docs/superpowers/plans/` — Dated implementation plans and probes.
- `docs/superpowers/specs/` — Design specs; some shipped, some partial. Check `docs/AGENT-READING-LIST.md` for status.
- `docs/playtests/` — Dated Playwright / human playtest reports. Do not confuse with `docs/playtesting/` (embodied AI harness, listed above).
- `docs/superpowers/playtests/` — Additional playtest artifacts.

## Verification commands

Use these for every change. The current test count is obtained by running the suite, not by reading a static number in a document.

```bash
npm install
npm run build   # app + tools TypeScript checks + Vite production build
npm test        # Vitest suite
npm run floor:validate
```

For renderer, combat, audio, and visual verification checklists, see [`AGENTS.md`](../AGENTS.md) and [`README.md`](../README.md).

## Constraints and gotchas

- Party size is four characters, not six. Source of truth: `src/game/party.ts` (`PARTY_SIZE`).
- Phaser 4 is the primary combat painter; `?phaser=0` is the Canvas 2D rollback backend.
- Seeded gameplay RNG lives in `src/game/rng.ts`; gameplay code should not use `Math.random()`.
- Do not casually rename enemy, item, perk, NPC, or floor IDs — they may be save-compatible identifiers.
- `docs/` is documentation-only. The GitHub Actions deploy builds and deploys `dist/`; never copy `dist/` into `docs/`.
- Root `*-preview.html` files are generated by `scripts/generate-*.mjs` and are gitignored. Regenerate on demand.
