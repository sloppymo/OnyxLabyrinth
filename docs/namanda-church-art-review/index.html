OnyxLabyrinth · Art & Room Production Review

Church of Saint Namanda — pale stone, censer, and four sacred services

Branch agent/saint-namanda-church. The second fully realized enterable Floor 1 micro-location, built as the deliberate counterpart to Hot Boi's Tavern: pale ivory ashlar stone, restrained candlelight, verticality, and restraint instead of clutter. 11 new assets (4 tileset materials + 2 altar panels + votive wall + reliquary niche + font + bench + kneeling rail), reusing the already-shipped hero door, Namanda's mark, and the hanging censer without regenerating any of them.

P0/P1 complete at 11 accepted assets from 15 generations (only the ceiling material needed rerolls, chasing a warm-not-purple palette). Room assembled, four real services wired to existing game systems, 2133 tests green, npm run check green. Stopped here — the room's four visual anchors (altar/relief, censer, votive wall, font) were judged complete; no side alcove was added (see §G for why).
Every in-engine screenshot below is a raw vite preview capture — no brightness/contrast inspection filter applied anywhere on this page. What you see is exactly what a player sees.

A. Source Art

All new assets generated via scripts/pixellab-generate.mjs against the PixelLab REST API (no MCP server configured in this repo — same path every prior art pass used). Reused assets are called out explicitly; none were regenerated.

B. Material Tile Tests

256×256 RGB, seamless. Darkened from the raw PixelLab output to the engine's mid-dark luminance band (wall ≈86, floorA ≈74, floorB ≈65, ceiling ≈54 — target band per docs/TILESET-ART-STYLE-GUIDE.md) after the first pass came back too bright to survive the renderer's contrast stretch. The ceiling needed three attempts to land on a warm cream rather than the model's default cool lavender-grey (Namanda's stone must not read as F4's cold purple).

C. Altar Composition

The apse is narrower than the nave (2 cells vs. 4) — a recessed niche, not a flat backdrop. namanda-altar and namanda-relief sit on the two apse cells' north walls (near-full-face, widthFrac 0.95 / heightFrac 0.95 / anchor bottom, the same technique as Hot Boi's bar composition). Namanda's mark is composited onto the relief panel's empty arch — tinted warm gilt, pixel-identical to the door's mark, never redrawn.

D. Wall Features

Deliberately not another centered rectangle: an irregular scattered candle cluster (one niche left cold on purpose — the room's one unexplained strange detail) and a tall narrow niche, on opposite nave walls.

E. Ceiling Piece

reused f1-censer — the existing accepted hanging censer from the ceiling-environment-art pass, already compatible with Namanda's material language. No new censer was generated. Placed mid-nave (10,5) to reinforce the entrance→altar sightline.

G. Final Room

Footprint: x=8–11, y=2–9 (4-wide nave/narthex, 2-wide apse, 1-wide threshold) — previously uncarved rock directly north of Sister Caldris's cut-bell chapel and above the ember-forge corridor, confirmed empty of every existing event/treasure/wallFeature/ceilingSprite before carving. Two tilesetZones (main room + a 1×1 threshold cell) keep the new "namanda" theme from bleeding onto Caldris's adjacent corridor cells.

The hero door was relocated, same asset, from (10,10)/(11,10) (the cut-bell-chapel↔ember-suture junction it originally shipped on) to (11,9)/(11,10) — the church's own mouth. The original coordinate is a live through-corridor shared with unrelated Floor 1 traffic; crossing it landed the party back in the ember-forge theme, failing the "immediate material transition" requirement. Relocating is a placement change, not a redesign — same PNG, same symbol, same severe pale-arch silhouette.
