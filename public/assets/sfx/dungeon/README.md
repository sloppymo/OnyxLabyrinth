# Dungeon and NPC sound placeholders

These WAV files are temporary implementation placeholders sourced from a
**Final Fantasy VI** (SNES) sound-effect rip. No license or permission from
Square Enix has been independently verified for this set. Treat their presence
as the project owner's risk assessment, not as cleared assets.

They intentionally live outside `assets/sfx/ui/`: that directory's permission
note applies only to its six named UI samples. Replace these files with cleared
final audio while preserving the stable filenames and engine cue IDs.

| File | Game cue | Source pack file | FF6US `$F4` reference |
|------|----------|------------------|------------------------|
| `chest-open.wav` | Fresh treasure awarded / safe trapped chest opened | `A6Switch.wav` | `$A6` — open treasure chest / switch |
| `npc-steal.wav` | Successful NPC theft | `5BThiefSteal.wav` | `$5B` — Steal |
